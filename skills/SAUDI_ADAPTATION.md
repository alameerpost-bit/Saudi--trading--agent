# تكييف حزمة Trader Skill للسوق السعودي

## المصدر
المصدر الأصلي: https://github.com/Jakeschincariol/trader-skill (MIT). الملفات الأصلية لم تُنسخ أو تُشغّل تلقائياً؛ هذا السجل يحدد المهارات ومتطلبات تكييفها.

## القرارات
| المهارة | القرار |
|---|---|
| trader-analyst | محلل ربعي سعودي أولي متاح كحسابات نقية على بيانات مقدمة من المستدعي؛ لا يزال ربط مصدر إفصاحات سعودي موثوق مطلوباً |
| trader-screener | ربط مقاييس مالية سعودية موثقة |
| trader-news | استبدال المصادر الأمريكية بمصادر أخبار وإفصاحات سعودية |
| trader-alerts | استخدام تقويم تداول ومصدر أسعار موثوق مع timestamp |
| trader-budget | تكييف الدولار إلى SAR ووحدات التداول المحلية |
| trader-risk | بناء قواعد تاسي وحدود المخاطر المعتمدة للمستخدم |
| trader-broker | محظور حتى وجود API رسمي موثق لسهم ومراجعة أمنية وموافقة مستقلة |
| trader-rebalance | يتطلب قراءة محفظة سهم للقراءة فقط وتكييف SAR |
| trader-tax | تعطيل قواعد الضرائب الأمريكية؛ دراسة تكلفة الاقتناء فقط |
| trader-copycat | مرجع 13F أمريكي فقط، لا يعمم على ملكيات تاسي |
| trader-pelosi | مرجع إفصاحات أمريكية فقط، غير مستخدم لإشارات تاسي |

## ضوابط إلزامية
1. لا تنفيذ آلي ولا endpoint لإرسال أو تعديل أو إلغاء أوامر.
2. لا تشغيل لسكربتات المصدر الأصلي قبل مراجعة كل مدخل ومخرج ومصدر بيانات.
3. لا إشارة دخول مع بيانات قديمة أو ناقصة أو بلا مصدر وتوقيت موثق.
4. كل محول سعودي يسجل المصدر ووقت المصدر ووقت الاسترجاع وحالة التأخير ورمز السوق.
5. تفعيل أي مهارة مشروط باختبارات وحدات وتكامل ومراجعة مستقلة.

## اختبار
`npm test` يتحقق من وجود 11 مهارة وبقاء مفاتيح التنفيذ معطلة.
